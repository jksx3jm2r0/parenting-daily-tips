# 女性促黄体生成素偏高有哪些饮食禁忌，这些饮食禁忌要知晓！

> 更新时间：2026-09-11 (UTC+8)

促黄体生成素偏高平时一定要忌口海鲜类食物，因为其会导致中风，而且还易引起中风。同时也不能吃辛辣食物，因为其会降低人体的免疫力，导致其他的并发症出现。除了这些食物外，还需要忌烟酒，因为其有害物质较多，会加重病情，导致不孕不育症状更加严重。建议日常多吃一些含有粗纤维的食物，比如大米、面食等，还可以多吃一些富含维生素c的水果蔬菜，比如鲜枣、橙子、油菜、芹菜等。同时还需要多补充一些豆制品、鸡蛋、牛奶、瘦肉等高蛋白食物。

促黄体生成素是一种促性腺激素，促黄体生成素与女性原发性闭经、继发性闭经、卵巢功能早衰、多囊卵巢综合征等有关，还与男性原发性睾丸功能低下、继发性睾丸功能低下有关。但促黄体生成素过高主要见于卵巢功能早衰、多囊卵巢综合征（持续性无排卵及雄激素过多等）等，可能会影响卵子质量，进而降低怀孕机率。

促黄体生成素可以促进女性卵泡成熟，如果促黄体生成素明显偏高，会导致内分泌失调，也会导致卵巢功能失调。大家在日常饮食中一定要忌口以下食物：

- 1. 海鲜：海鲜含有大量嘌呤和过敏成分，容易诱发痛风，加重身体不适，影响疾病恢复；
- 2. 辛辣食物：辣椒、茴香、芥末、咖喱、韭菜、蒜苗等辛辣食物，容易增加并发症的概率；
- 3. 烟酒：烟酒含有大量有害物质，长期使用可能会加重身体不适，影响病情恢复；
- 4. 刺激性饮料：不能喝浓茶、咖啡、绿茶、红茶、红牛、可乐等刺激性饮料，否则可能会加重病情。

对于促黄体生成素高的女性，饮食应避免寒冷、辛辣、刺激，少吃甜食和油腻食物。平时要吃清淡易消化的饮食，多吃新鲜水果蔬菜，不要挑食，也不要暴饮暴食。一般情况下，促黄体生成素只有在排卵前1-2天才会出现短期高值，通常较低。
